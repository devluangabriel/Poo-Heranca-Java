# Herança Orientada a Objeto em Java

Este projeto foi desenvolvido com o objetivo de aprofundar meus conhecimentos em Programação Orientada a Objetos (POO). Nele, coloco em prática conceitos fundamentais como herança, encapsulamento e reutilização de código utilizando a linguagem Java. O código foi estruturado de forma didática, visando facilitar o entendimento e a aplicação dos princípios da POO em projetos reais. Este repositório faz parte do meu processo de aprendizagem e pode servir como base para outros estudantes que desejam entender na prática como a herança funciona na linguagem Java.
